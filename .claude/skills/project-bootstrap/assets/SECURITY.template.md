## Reporting a vulnerability

Report security problems privately, never in a public issue, pull request or discussion. Use one private channel:

- the hosting platform's private vulnerability reporting (on GitHub: Security tab, then **Report a vulnerability**), or
- a dedicated security mailbox owned by the team (not a personal address).

Include the affected component and version, steps to reproduce, and the expected impact. Do not include real secrets or personal data.
