# v1.1.0 - Core API for the Web, iOS and Android Clients
## Projects 27 v1.1.0: Core API for the Web, iOS and Android Clients

The finance system gets its back end: one API and one contract that the web app, the Swift iOS app and the Dart Android app will all use.

### Key Highlights
- **Ledger the database protects**: balanced entries, immutable postings, closed months and an append-only hash-chained audit trail are enforced by PostgreSQL 18 itself, not only by the application.
- **Exact rupiah**: amounts are decimal strings on the wire and integer sen in storage; floating point is rejected.
- **Personal entity in IDR** created at sign-up, with a starting chart of accounts.
- **Sign-in**: Argon2id passwords, optional TOTP two-factor, HttpOnly cookies for the web and bearer tokens for native apps.
- **Reports with self-checks**: monthly income and expense recap, trial balance, income statement and balance sheet; month close stores hashed snapshots that anyone can cross-check.
- **One contract**: OpenAPI 3.1 plus a shared sample ledger; tests prove the API matches both.
