## Projects 24 v1.11.0: Only the Human Author Is Credited

Work done with AI agents is still the owner's work: commits, tags, releases and pull requests credit only the human author, and CI proves it.

### Key Highlights
- **Non-negotiable 12** in `AGENTS.md` and **rule 08**: no `Co-Authored-By`, sign-off or similar trailer, "Generated with" line, or author, committer or bot identity that credits an AI agent; human co-authors who really took part may still be credited.
- **`scripts/check-authorship.mjs`** and a new **Authorship** CI job scan the full history; the installer copies the script into projects.
- **Skills** that write commits, release automation and release notes point to the rule where it applies.
