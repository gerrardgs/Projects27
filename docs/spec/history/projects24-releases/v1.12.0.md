# v1.12.0 - Plan First, Blind Spots and the Chaos Engineering Cycle
## Projects 24 v1.12.0: Plan First, Blind Spots and the Chaos Engineering Cycle

Agents now propose before they act, check what they might have missed against more than one source, and prove resilience with a complete chaos engineering cycle.

### Key Highlights
- **Plan first, act only after approval** (`AGENTS.md` non-negotiable 13, rule 15 section 1): an implementation plan with goal, context, assumptions, verified steps, blind spots, risks and rollback for every change, and nothing that writes runs before the user approves it.
- **Plan mode in Claude Code**: `.claude/settings.json` starts terminal sessions in plan mode, so edits are blocked until the plan is approved; `CLAUDE.md` explains the VS Code setting.
- **Blind spots, cross-checks and objective validation** (rule 03 section 6): two independent sources for every relied-on fact, current and maintained standards and tools, and success judged by measured evidence only.
- **Chaos engineering cycle** (skill section 5): steady state, failure hypothesis, chaos with a blast radius and abort conditions, observation, evaluation, and an improvement plan that is re-tested, recorded with the new experiment record template.
