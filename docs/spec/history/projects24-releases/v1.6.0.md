# v1.6.0 - Engineering Concepts and Chaos Engineering
## Projects 24 v1.6.0: Engineering Concepts and Chaos Engineering

Resilience is now designed in and proven by experiment, and every major engineering body of knowledge is mapped to the rules and skills that apply it.

### Key Highlights
- **resilience-and-chaos-engineering skill**: the Principles of Chaos Engineering, a catalogue of front-end failure modes, resilience patterns for user interfaces (timeouts, retries with backoff and jitter, circuit breakers, error boundaries, kill switches), SLOs and error budgets, and rules for production game days.
- **browser-chaos template**: six experiments (scripts, styles, slow network, storage, offline) with a user-visible steady state, injected only in the test browser; tests prove a fragile page is caught.
- **ENGINEERING-CONCEPTS.md**: the 18 SWEBOK V4.0 knowledge areas, the ISO/IEC 25010:2023 quality model, design and architecture principles, DORA metrics, SRE, security and accessibility engineering, each mapped to a rule or skill.
- **Fault-injection tools with current versions**: Toxiproxy, Chaos Toolkit, LitmusChaos and Chaos Mesh, plus managed services.
