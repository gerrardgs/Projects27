## Toolchain for stage 4 (status on 2026-10-28)

- Android: installed with the owner's approval: Flutter 3.47.8 (Dart included), Android Studio 2026.2.1, Android SDK command-line tools with platform 36, platform-tools 37.0.1, the emulator and an Android 36 arm64 system image, OpenJDK 21. Installing the SDK accepted the Android SDK licence on the owner's behalf.
- iOS: Xcode 27.1 licence accepted by the owner on 2026-10-28; iOS 27.1 Simulator runtime installed; XcodeGen 2.46.0 installed with Homebrew for the project file. Earlier note: before the licence was accepted, Until the owner runs `sudo xcodebuild -license accept` and `sudo xcodebuild -runFirstLaunch` in a terminal (an agent cannot type the administrator password, and accepting Apple's licence is the owner's decision), every tool that goes through `xcrun` or the Xcode `git` refuses to run. Android builds work around it per process with `DEVELOPER_DIR=/Library/Developer/CommandLineTools`, which changes no system setting and accepts no licence; host `flutter test` still fails because the `objective_c` build hook calls `xcrun` in a cleaned environment. An Apple Developer account is needed before installing on a device or publishing.
- Passkeys and deployment still wait for the hosting decision.
